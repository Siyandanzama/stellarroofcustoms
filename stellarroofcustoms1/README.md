# stellarroofcustoms
Project Overview

StellarRoof Customs is a luxury automotive customisation business specialising in fibre optic star light headliner installations for vehicles. This website was developed to create an online presence for the business, showcase services and allow potential customers to make enquiries and bookings.

The project was developed using basic front-end web technologies including HTML, CSS, and JavaScript.

Project Objectives

The objectives of this website are to:

.Create a professional online presence
.Showcase automotive lighting services
.Improve customer engagement
.Provide an enquiry and contact platform
.Demonstrate responsive and visually appealing web design principles
